# Bug Fix Flow

1) Intake & triage
- Create a structured bug ticket from logs/user reports
- Capture repro steps, expected vs actual, and impact

2) Investigation
- Identify likely root cause area
- Decide fix approach and expected side effects

3) Fix & regression
- Implement fix following conventions
- Add regression tests to prevent recurrence

4) Release & notes
- Deploy via standard pipeline
- Document troubleshooting notes if useful
