# Feature Delivery Flow (PM story → Dev technical tickets)

1) User story (PM / Project Manager)
- Defines goal, scope, and acceptance criteria
- Includes links (designs, docs) and constraints

2) Technical decomposition (Developers)
- Break down into technical Jira tickets by area (Backend/Web/Mobile/Data/DevOps/QA)
- Identify dependencies and sequencing
- Confirm any missing requirements

3) Implementation
- Use Backend/Mobile/Web agents for scaffolding and drafts
- Keep code aligned with repo conventions

4) Testing
- Add automated tests alongside implementation
- Include failure cases and edge cases early

5) Documentation
- Update technical docs and runbooks when behavior or operations change

6) Review & release
- Standard PR review and release flow
- AI output is reviewed; humans approve and ship
