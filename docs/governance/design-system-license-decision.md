# Design System License Decision

## Current decision

Licensing approval is pending. Until written approval is recorded, the default for the v2 public demo is an original Agilno demo design system and original Agilno-owned components.

Untitled UI, or any other third-party design system, component kit, template, icon set, font, or asset package, may be used only after written confirmation establishes that the intended use, modification, distribution, and redistribution are permitted for the demo and any released source or artifacts.

## Decision record

| Field | Status / required evidence |
| --- | --- |
| Decision owner | Pending — must be an authorized Agilno legal, licensing, or product owner |
| Decision date | Pending |
| Candidate asset or kit | Pending; identify exact product, version, and source |
| License reviewed | Pending; record exact license name and version |
| Evidence | Pending; link or identifier for written license and redistribution confirmation in the governed internal system |
| Approved scope | Pending; document allowed use, modification, distribution, attribution, and redistribution conditions |
| Result | Pending; original Agilno design system remains the default |

No third-party kit may enter a public-demo build until every required field is complete and the result explicitly says **approved**. If evidence is missing, ambiguous, or does not cover redistribution, the decision remains **blocked** and original Agilno components must be used.
